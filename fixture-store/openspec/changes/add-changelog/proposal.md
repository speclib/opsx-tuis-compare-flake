# Add a changelog

## Why

Release notes are currently written from the commit log by hand, which means
they are written differently every time and sometimes not at all.

## What Changes

- Keep a changelog file updated as part of every release.

## Capabilities

### Modified Capabilities

- `release-process`: a release also updates the changelog.

### New Capabilities

None.

## Impact

- One new file, and one more step in the release checklist.
